# لعبة المزاد — Prototype تجريبي

ده أول نسخة شغالة من لعبة "المزاد" عشان تجربها بنفسك (تقدر تفتح تابين في المتصفح وتلعب بيهم كأنك لاعبين مختلفين).

## اللي هتحتاجه
- إنك مسطب **Node.js** بالفعل (زي ما قلتلي).

## خطوات التشغيل (مرة واحدة بس أول مرة)

1. فك ضغط الملف اللي هتاخده (المجلد `almazad`).
2. افتح الـ Terminal (أو Command Prompt / PowerShell على ويندوز).
3. روح لمكان المجلد، مثلاً:
   ```
   cd Desktop/almazad
   ```
4. نزّل المكتبات المطلوبة (مرة واحدة بس):
   ```
   npm install
   ```
5. شغّل السيرفر:
   ```
   npm start
   ```
6. هتلاقي رسالة زي:
   ```
   Almazad server running: http://localhost:3000
   ```

## إزاي تلعب لوحدك (تجربة)

1. افتح المتصفح على: `http://localhost:3000`
2. اكتب اسمك واضغط **"أنشئ غرفة (Host)"** — هيديك كود غرفة (4 حروف/أرقام).
3. افتح **تاب جديد** (أو متصفح تاني) على نفس اللينك، واكتب اسم تاني، وادخل بنفس كود الغرفة (**"انضم لغرفة"**).
4. من أي تاب: اعمل **فريقين على الأقل** (زرار "فريق جديد")، وخلي كل تاب ينضم لفريق مختلف.
5. من التاب الأول (الـHost)، اضبط الإعدادات لو حابب (مدة المزاد، مدة الشرح، الهدف بالنقاط، صعوبة الكلمات) واضغط **"ابدأ المباراة"**.
6. اللعبة هتشتغل بالضبط زي المنطق المكتوب فى ملف الـSpecification:
   - كل جولة يتم اختيار لاعب من كل فريق، وتظهر له الكلمة لوحده.
   - مرحلة المزاد: كل لاعب مشارك يختار 1 أو 2 أو 3 كلمات.
   - أقل Bid يفوز (وعند التعادل الأسرع فى الإرسال يفوز، حسب وقت السيرفر مش وقت جهازك).
   - الفائز يشرح لفريقه، والـHost عنده زرار "✅ صح" يضغطه لو الفريق خمّن صح.
   - لو خلص الوقت من غير ما حد يعرف، يتقدّم الدور للفريق اللي بعده حسب ترتيب الـBids.
   - لو كل الفرق فشلت، بيظهر تصويت "نكمل / كلمة جديدة".
   - أول فريق يوصل للهدف (12 نقطة افتراضيًا) يفوز باللعبة.

## ملاحظات مهمة عن النسخة دي

- دي نسخة **Prototype** أولية لتجربة المنطق، مش نسخة نهائية جاهزة للنشر.
- البيانات كلها فى ذاكرة السيرفر (RAM) فقط — لو قفلت السيرفر أو عملت له Restart، كل الغرف والنتائج بتتمسح.
- لو حد قفل التاب بتاعه (Host) المباراة بتتوقف تلقائيًا.
- قاعدة "منع تكرار الكلمة لمدة 7 أيام" (بند 7 فى التوثيق) مطبقة بشكل مبسّط هنا: الكلمة مش بترجع تاني إلا لما مخزون الكلمات المتاح لنفس مستوى الصعوبة يخلص، لأن النسخة دي مفيهاش قاعدة بيانات دائمة بتفتكر التاريخ بين الجلسات.
- بنك الكلمات فى الملف `words.js` صغير للتجربة (حوالي 50 كلمة) — سهل جدًا تزود عليه كلمات جديدة.
- تصويت "الاستمرار / كلمة جديدة" (بند 17) لسه مبسّط: أول فريق يوافق يكفي عشان يكمل، وده مطابق للقاعدة المذكورة فى بند 23 من التوثيق (يكفي موافقة فريق واحد).
